Fichiers

  1. Les lignes directrices : IMPORTANT.md et IMPORTANT.txt, en anglais ; IMPORTANTE.md et IMPORTANTE.txt, en portugais.
  2. Ce lisez-moi :
    1. README.md : en anglais, le texte canonique de rédaction ; toute modification commence ici.
    2. README.txt : extrait de README.md.
    3. readme.html : la page canonique de publication, incluse dans sitemap.xml.
    4. Les traductions, une pour chaque langue des pays où Amazon vend les livres publiés avec KDP : eBooks Kindle, livres brochés (paperback) ou reliés (17 boutiques). Chacune a son .md, son .txt et son .html :
      1. portugais : README.pt.md, README.pt.txt et readme.pt.html ;
      2. italien : README.it.md, README.it.txt et readme.it.html ;
      3. allemand : README.de.md, README.de.txt et readme.de.html ;
      4. français : README.fr.md, README.fr.txt et readme.fr.html ;
      5. espagnol : README.es.md, README.es.txt et readme.es.html ;
      6. hindi : README.hi.md, README.hi.txt et readme.hi.html ;
      7. néerlandais : README.nl.md, README.nl.txt et readme.nl.html ;
      8. japonais : README.ja.md, README.ja.txt et readme.ja.html ;
      9. polonais : README.pl.md, README.pl.txt et readme.pl.html ;
      10. suédois : README.sv.md, README.sv.txt et readme.sv.html.
    5. Les noms suivent le standard du marché : README.<langue>.md, avec le code de langue BCP 47, sans la région.
    6. Tous les fichiers sont en UTF-8, dans toutes les langues.
  3. Les fichiers des agents d'IA, avec les instructions pour les agents, tous avec le même texte, qui mènent au dépôt privé : AGENTS.md, CLAUDE.md, GEMINI.md et .github/copilot-instructions.md.
  4. CNAME : le domaine propre (senajg.com.br).
  5. .nojekyll : publie les fichiers tels qu'ils sont (nécessaire pour les dossiers avec un point dans le nom).
  6. .gitattributes : les règles de Git pour les fichiers (fins de ligne, et images en binaire).
  7. robots.txt : le seul que les moteurs de recherche lisent sur le domaine ; il indique le sitemap.
  8. sitemap.xml : le sitemap avec les pages en portugais (celles en anglais sont dans le sitemap de senajg.com) et, depuis la rev.82, les pages du lisez-moi.
  9. google484cfeadc0c124ef.html : la vérification de Google Search Console.
  10. 404.html : la page d'erreur, avec un bouton vers la page d'accueil.
  11. favicon.ico : l'icône de l'onglet du navigateur (mandala bleu, 16, 32 et 48 px).
  12. apple-touch-icon.png : l'icône de 180×180 pour ceux qui enregistrent le site sur l'écran d'accueil d'un iPhone ou d'un iPad.
  13. assets/ : les couvertures des cartes et les icônes des pages principales, et aussi :
    1. aco-escovado.js : les boutons de métal qui tournent ;
    2. seta-voltar.js : la flèche du bouton Retour, qui tourne ;
    3. les photos du miroir de la ville des boutons Kindle : mirror-city.webp et mirror-eagle.webp ;
    4. le fond de la Réalité : fundo-bolhas.js (les images d'univers-bulles qui se relaient, de universo-bolha-1.webp à universo-bolha-4.webp) et cubos-metal.webp (les cubes de métal).
  14. sitemap-antigos.xml : le sitemap temporaire des 17 anciennes adresses (rev.60), envoyé seulement dans Search Console. Il sera retiré d'ici le 10/12/2026.
