ファイル
----

1. ガイドライン： IMPORTANT.md と IMPORTANT.txt（英語）、IMPORTANTE.md と IMPORTANTE.txt（ポルトガル語）。
2. この README：
   1. README.md：英語。執筆の正本で、すべての変更はここから始まります。
   2. README.txt：README.md から取り出したもの。
   3. readme.html：公開の正本となるページで、sitemap.xml に載っています。
   4. 翻訳：Amazon が KDP で出版された本（Kindle 電子書籍、ペーパーバック、ハードカバー）を販売している国の言語ごとに一つあります（17 のマーケットプレイス）。それぞれに .md、.txt、.html があります：
      1. ポルトガル語：README.pt.md、README.pt.txt、readme.pt.html
      2. イタリア語：README.it.md、README.it.txt、readme.it.html
      3. ドイツ語：README.de.md、README.de.txt、readme.de.html
      4. フランス語：README.fr.md、README.fr.txt、readme.fr.html
      5. スペイン語：README.es.md、README.es.txt、readme.es.html
      6. ヒンディー語：README.hi.md、README.hi.txt、readme.hi.html
      7. オランダ語：README.nl.md、README.nl.txt、readme.nl.html
      8. 日本語：README.ja.md、README.ja.txt、readme.ja.html
      9. ポーランド語：README.pl.md、README.pl.txt、readme.pl.html
      10. スウェーデン語：README.sv.md、README.sv.txt、readme.sv.html
   5. 名前は業界の標準に従います：README.<言語>.md。言語は BCP 47 の言語コードで、地域は付けません。
   6. すべてのファイルは、どの言語でも UTF-8 です。
3. AI エージェント用のファイル： エージェントへの指示が書かれ、すべて同じ内容で、非公開リポジトリへ案内します：AGENTS.md、CLAUDE.md、GEMINI.md、.github/copilot-instructions.md。
4. CNAME：独自ドメイン（senajg.com.br）。
5. .nojekyll：ファイルをそのままの形で公開します（名前に点が入ったフォルダーのために必要です）。
6. .gitattributes：ファイルに関する Git のルール（改行コードと、画像をバイナリとして扱うこと）。
7. robots.txt：検索エンジンがこのドメインで読む唯一の robots.txt です。サイトマップの場所を示します。
8. sitemap.xml：ポルトガル語のページを載せたサイトマップ（英語のページは senajg.com のサイトマップにあります）。rev.82 からは README のページも載せています。
9. google484cfeadc0c124ef.html：Google Search Console の確認用ファイル。
10. 404.html：エラーページで、ホームページへのボタンがあります。
11. favicon.ico：ブラウザーのタブのアイコン（青いマンダラ、16、32、48 px）。
12. apple-touch-icon.png：iPhone や iPad のホーム画面にウェブサイトを追加する人のための、180×180 のアイコン。
13. assets/：カードの表紙とメインページのアイコン。ほかに次のものがあります：
    1. aco-escovado.js：回転する金属のボタン
    2. seta-voltar.js：「戻る」ボタンの回転する矢印
    3. Kindle ボタンの街の鏡の写真：mirror-city.webp と mirror-eagle.webp
    4. Reality の背景：fundo-bolhas.js（入れ替わる泡宇宙の画像、universo-bolha-1.webp から universo-bolha-4.webp まで）と cubos-metal.webp（金属の立方体）
14. sitemap-antigos.xml：17 の古いアドレスのための一時的なサイトマップ（rev.60）で、Search Console だけで送信しました。2026年12月10日までに削除します。
