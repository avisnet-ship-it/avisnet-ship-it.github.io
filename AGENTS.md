# AGENTS.md — para agentes de IA

> **Se você é uma IA chegando a este repositório:** ele é só a saída. As páginas daqui são feitas pelos programas do repositório privado do projeto, `avisnet-ship-it/privado`, que é a memória de tudo: as regras de trabalho com o autor, a ordem de leitura, os procedimentos e a infraestrutura. **Comece pelo `AGENTS.md` do privado** (é preciso ter acesso a ele, dado pelo autor).

- Não mude as páginas daqui direto: a mudança vai para os programas do privado, e a conferência da reconstrução tem de refazer este site exatamente (`docs/runbook.md` do privado).
- Antes de qualquer coisa de versão, branch, tag ou Release, leia o `VERSIONING.md` do privado.
- Este repositório é público: nada interno entra aqui, e os únicos e-mails permitidos são os de contato dos domínios.
